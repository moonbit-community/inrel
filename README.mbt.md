# inrel

MoonBit implementation workspace for inductive-relation-driven test generation.

Current status:

- Core DSL abstractions are implemented in subpackages.
- Automatic derive is intentionally out of scope for now.

Packages:

- `CAIMEOX/inrel/dsl/spec`
- `CAIMEOX/inrel/dsl/unify`
- `CAIMEOX/inrel/dsl/gen`

## Reference
